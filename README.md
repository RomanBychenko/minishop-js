# MiniShop

Навчальний інтернет-магазин електроніки на HTML, CSS та JavaScript. Сервер працює на Node.js без сторонніх пакетів. У проєкті можна оформлювати замовлення, обробляти чергу, імпортувати великі файли та переглядати журнал.

Автор: Roman Bychenko.

## Запуск

Потрібен Node.js (проєкт розрахований на версію 24).

```bash
npm --prefix app install
npm --prefix app start
```

Відкрити http://127.0.0.1:3000 у браузері. Сервіс доставки запускається автоматично на порту 3001. Для зупинки — Ctrl+C у терміналі.

## Як працює магазин

- Каталог: додати товар до кошика, змінити кількість і оформити замовлення.
- Замовлення: згенерувати тестові записи, вибрати порядок черги та спосіб авторизації, запустити або скасувати обробку.
- Імпорт: створити тестовий JSONL або вибрати власний файл. Результат записується у `app/data/generated/imported-orders.jsonl`, статистика показується на сайті. Імпорт не додає всі записи до черги в пам'яті.
- Журнал: переглянути події, статистику кешу, HTTP-запити та останні записи логів.

Активна черга та статистика зберігаються до перезапуску сервера. Логи і файли імпорту залишаються на диску. Авторизація локальна, з тестовими ключами, не призначена для реальних платежів чи відкритого сервера.

## Структура

- `library` — власний пакет `minishop-utils` з функціями лабораторних.
- `app` — сервер та логіка магазину.
- `app/public` — HTML, CSS та JavaScript вебінтерфейсу.
- `app/examples` — окремі приклади і перевірки.

## Лабораторні роботи

| № | Файли | Де використано |
|---|---|---|
| 1. Generators and Iterators | `generator.js`, `iterator.js` | Генерація тестових замовлень протягом заданого часу. |
| 2. Project Setup | `library/package.json`, `app/package.json`, `library/index.js` | Підключення власного пакета через локальну npm-залежність. |
| 3. Memoization | `memoize.js`, `cachePolicies.js`, `pricing.js` | Кешування вартості, знижки та доставки. LRU, LFU, TTL і CUSTOM показано в прикладі. |
| 4. Priority Queue | `priorityQueue.js`, `orderQueue.js` | Черга замовлень, peek/dequeue, highest/lowest, FIFO та LIFO. |
| 5. Async Array | `asyncMap.js`, `orderProcessing.js` | Асинхронний map через callback та Promise, async/await, скасування через AbortController. |
| 6. Streams | `streams.js`, `orderImport.js` | Потокова генерація та імпорт JSONL без завантаження всього файлу в пам'ять. |
| 7. Reactive Communication | `events.js`, `shopEvents.js` | Події замовлень, незалежні підписники, статистика, повідомлення та відписка. |
| 8. Authentication Proxy | `authProxy.js`, `deliveryClient.js`, `deliveryApi.js` | Запити до сервісу доставки через API Key, JWT або навчальний OAuth, оновлення токенів, ліміти та журнал HTTP-відповідей. |
| 9. Logging Decorator | `logger.js`, `shopLogger.js` | Логування обробки замовлень. INFO, DEBUG, ERROR, час, власний формат і запис у консоль, файл або HTTP-сервіс. |

## Перевірка

Кожну лабораторну можна запустити окремо, наприклад:

```bash
npm --prefix app run lab1
npm --prefix app run lab3
npm --prefix app run lab9
```

Доступні команди `lab1` – `lab9`. Друга лабораторна запускає приклад підключення бібліотеки. Перевірка інтеграції магазину:

```bash
npm --prefix app run check
```

Під час перевірки створюються тестові файли та записи журналу. Ліцензія MIT.
