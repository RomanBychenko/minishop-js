# MiniShop

MiniShop — простий інтернет-магазин, розроблений на JavaScript. Проєкт створюється для практичного використання механізмів програмування, розглянутих у лабораторних роботах.

Автор: Роман Биченко

## Запуск

Для роботи проєкту необхідно встановити Node.js.

Встановлення залежностей:

```bash
npm --prefix app install
```

## Структура проєкту

- `library` — власна бібліотека з функціями лабораторних робіт.
- `app` — основна програма магазину.
- `app/examples` — приклади використання функцій бібліотеки.

## Лабораторні роботи

### Lab 1 — Generators and Iterators

Створено нескінченний генератор чисел та генератор тестових замовлень. Також реалізовано функцію, яка отримує значення з ітератора протягом заданого часу.

Запуск прикладу:

```bash
npm --prefix app run lab1
```

### Lab 2 — Project Setup

Проєкт розділено на бібліотеку та основну програму. Бібліотека підключається через локальну залежність у package.json.

Перевірити роботу бібліотеки можна за допомогою прикладу першої лабораторної:

```bash
npm --prefix app run lab2
```

### Lab 3 — Memoization

У файлі memoize.js реалізовано кешування результатів
функцій. У cachePolicies.js знаходяться стратегії
очищення кешу: LRU, LFU, TTL та CUSTOM.

У pricing.js мемоізація використовується для
розрахунку вартості замовлення та доставки.

Запуск: npm --prefix app run lab3

### Lab 4 — Priority Queue

У файлі priorityQueue.js реалізовано чергу з
пріоритетами. Елементи можна отримувати за
найвищим або найнижчим пріоритетом, а також
у порядку FIFO та LIFO.

У orderQueue.js черга використовується для
збереження та отримання замовлень магазину.

Запуск: npm --prefix app run lab4

### Lab 5 — Async Array

У файлі asyncMap.js реалізовано асинхронну
версію функції map через callback та Promise.
Також додано можливість скасування операції
через AbortController.

У orderProcessing.js ці функції використовуються
для асинхронної обробки замовлень.

Запуск: npm --prefix app run lab5

### Lab 6 — Large Data Processing

У файлі streams.js реалізовано генерацію,
читання та обробку великих JSONL-файлів
за допомогою Streams та Async Iterators.

У orderImport.js ці функції використовуються
для імпорту замовлень магазину.

Приклад обробляє 100000 замовлень без
завантаження всього файлу в оперативну пам'ять.

Запуск: npm --prefix app run lab6

### Lab 7 — Reactive Communication

У файлі events.js реалізовано систему подій
на основі EventEmitter.

У shopEvents.js знаходяться підписники,
які відповідають за повідомлення та статистику
замовлень. Підтримується підписка та відписка.

Запуск: npm --prefix app run lab7

### Lab 8 — Authentication Proxy

У файлі authProxy.js реалізовано обгортку
для HTTP-запитів з авторизацією.

У deliveryApi.js створено локальний сервіс
доставки, а в deliveryClient.js реалізовано
способи авторизації API Key, JWT та OAuth.

Також додано оновлення токенів, обмеження
кількості запитів та логування HTTP-відповідей.

Запуск: npm --prefix app run lab8

### Lab 9 — Logging Decorator

У файлі logger.js реалізовано декоратор
для логування синхронних та асинхронних функцій.

Підтримуються рівні INFO, DEBUG та ERROR,
власне форматування та вимірювання часу роботи.

У shopLogger.js реалізовано запис логів
у файл та надсилання до HTTP-сервісу.

Декоратор використовується під час
обробки замовлень магазину.

Запуск: npm --prefix app run lab9
